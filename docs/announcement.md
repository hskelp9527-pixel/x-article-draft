# 试用介绍文案

做了一个开源 Skill：x-article-draft，把 Obsidian 长文和已有图片一起存进 X Articles 草稿。

写文章时直接粘贴的截图，经常散落在附件文件夹里。这个 Skill 会根据笔记里的引用找图，保留图片在正文中的顺序，你不用先把它们挪到同一个目录。

默认走浏览器，复用登录状态，不要求每个人申请 API；也提供官方 API 路线，把申请入口、配置和授权步骤整理好，首次配置后复用。

目前是实验版：本地与模拟测试已通过，真实账号投递还在等待试用验证。浏览器路线需要 Agent 本身支持浏览器控制，只保存草稿，发布由你决定。

项目：https://github.com/hskelp9527-pixel/x-article-draft

欢迎试用，并在 Issues 留下系统、Agent 宿主和遇到的问题。记得去掉私人文章与登录信息。
