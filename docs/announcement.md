# 试用介绍文案

做了一个开源工具：x-article-draft，把 Obsidian 长文和已有图片一起存进 X Articles 草稿。

写文章时直接粘贴的截图，经常散落在附件文件夹里。这个 Skill 会根据笔记里的引用找图，保留图片在正文中的顺序，你不用先把它们挪到同一个目录。

现在有 Obsidian 插件：打开文章，点左侧“存到 X 草稿”就开始。默认由插件自己操作专用 Chrome，首次登录后复用登录状态，不需要打开 AI 对话，也不要求每个人申请 API。还保留 Agent Skill 和可选官方 API 路线。

目前是实验版：本地与模拟测试已通过，插件的独立 Chrome 流程也在本地仿真编辑器验证过，真实 X 账号投递还在等待试用。只保存草稿，发布由你决定。

项目：https://github.com/hskelp9527-pixel/x-article-draft

欢迎试用，并在 Issues 留下系统、Agent 宿主和遇到的问题。记得去掉私人文章与登录信息。
